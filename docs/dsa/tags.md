## 📖 How to Use Tags

Every topic file is tagged with relevant keywords so you can discover related problems across different categories.

**Example tags you'll find:**

- **Data structures**: `array`, `string`, `linked-list`, `tree`, `graph`, `trie`, `heap`
- **Techniques**: `two-pointers`, `sliding-window`, `binary-search`, `backtracking`, `dp`, `greedy`
- **Concepts**: `hashing`, `recursion`, `bfs`, `dfs`, `divide-and-conquer`, `bit-manipulation`
- **Difficulty**: `easy`, `medium`, `hard`
- **Meta**: `neetcode-150`, `interview`, `classic`

**To add tags to a page**, add a YAML front matter block at the top:

```markdown
---
tags:
  - array
  - two-pointers
  - easy
  - neetcode-150
---

# Two Sum II
...
```

Tags will automatically appear on this page.
