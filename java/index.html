    ☕ Core Java — Interview Revision¶

    Welcome to the Core Java revision section. This is not a tutorial — it's a concept-dense reference written for engineers who already write Java daily and want to sharpen the why before interviews.

    Every document here follows the same shape:

    • Mental model — intuition first
    • Internals — what the JVM / compiler actually does
    • Tricky corners — the edge cases interviewers love
    • Common pitfalls and Key interview tips at the bottom

    Topic What You'll Learn
    Collections Overview Hierarchy, List/Set/Map/Queue, when to use what

    Streams & Functional Full Streams deep dive (JDK 21), lambdas, functional interfaces, collectors

    Topic What You'll Learn

    Synchronization synchronized, volatile, wait/notify, ReentrantLock
    Executors & Futures ExecutorService, Future, CompletableFuture, thread pool tuning
    Concurrency Utilities Semaphore, CountDownLatch, CyclicBarrier, AtomicInteger, CAS
    Deadlock & Liveness Detection, prevention, starvation, livelock, thread dumps
    Virtual Threads Java 21 virtual threads, pinning, structured concurrency

    Topic What You'll Learn

    Design Patterns Advanced Abstract Factory, Composite, Bridge, Flyweight, State, Command, Visitor + DI, Repository, Circuit Breaker, Saga

    JVM Tools JVM flags, heap sizing, GC logging, jps/jmap/jstat/jstack/jcmd, JFR, diagnostic workflows
